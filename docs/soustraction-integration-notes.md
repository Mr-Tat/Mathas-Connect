# Soustraction — périmètre d'intégration

Le moteur copié reste identique à celui du dépôt autonome. Les modes officiels sont Calculs classiques (4, 10, 20), exercice guidé sans score, Mort subite séparée pour les techniques Compensation et Emprunt direct, HARD 5 calculs et HARD Mort subite. Les XP suivent les mêmes seuils par niveau que les autres calculs écrits uniquement parce que les modes et volumes réellement vérifiés sont compatibles ; les deux techniques de Mort subite partagent les jalons XP de niveau, tout en conservant leurs records distincts. Le professeur gère les reprises par `app_key`, jamais globalement.

La publication utilise une inscription `enabled=false` et quatre présélections `visible=false` tant qu'une recette complète n'a pas été validée. Aucune authentification élève réelle n'est simulée par les tests automatisés. Aucun fichier du dépôt autonome n'est modifié.

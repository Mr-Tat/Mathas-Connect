Calculs écrits mélangés devient une application Connect indépendante : copie du moteur V6.0.2 préservant les méthodes natives, pont terminal unique, records 4/10/20 séparés et sauvegarde isolée par classe/JWT/élève/app. La file offline conserve les preuves jusqu’à l’ACK ; état, crédits et reçu sont atomiques. Les quatre moteurs existants sont inchangés.

Le professeur a autorisé le 31 octobre la livraison aux élèves. Les sessions utilisent les contrôles Connect habituels sans nouveau secret : JWT, appareil approuvé, élève actif et inscrit, ou professeur gestionnaire avec Monsieur T séparé. Les overrides de fermeture et de pilote restent respectés. L’installation garde l’app désactivée et les quatre cartes masquées ; une recette publiée sur profil fictif précède leur visibilité. Les versions des scripts de portail/HUB sont actualisées.

Le plafond reste **594 XP** : une opération cochée au départ = 25 %, deux = 50 %, trois = 100 %, même pour un tirage chanceux. Une nouvelle réussite ne verse que les compléments manquants. Master/entraînement/challenge dormant donnent 0. Les règles des autres jeux ne changent pas. Le hub propose résultats, XP, reset et tables minimales propres à Mélange par classe ou élève, indépendamment de Multiplication simple.

L’audit récent fourni en lecture seule est conforme : 26 tables, 13 fonctions, watchers et presets parents inchangés, 25 migrations et aucun objet Mélange. Le fichier d’installation final vise l’historique géré à six colonnes : corps SQL approuvé inchangé, une ligne d’historique avec idempotence dans la même transaction, aucun replay historique. Le fichier de migration correspondant est versionné. L’enveloppe complète se lance comme un seul lot SQL brut, jamais via un outil qui ajouterait sa propre ligne d’historique.

Validation locale : **225 tests Node, 224 réussis, 0 échec, 1 historique Soustraction/pg ignoré** ; PostgreSQL (trois taux, 594/27 droits, CAS, reçus, reset/rejeu, quatre états de catalogue et arrêt non destructif) ; Auth/Edge/PostgreSQL/Chromium réel sans secret de pilote (7 → 14 → 28, offline sans XP anticipé, répétition0, professeur, tables, Monsieur T, réaffectation JWT et file100). La CI exécute le fichier d’installation exact sur 25 historiques fictifs, vérifie son enregistrement unique, les anciennes lignes intactes et le rollback tardif.

Cette préparation ne prouve pas qu’une opération hébergée ou une recette publiée a déjà été exécutée. Le lot SQL/Edge/Pages et la recette doivent être tracés au SHA effectivement livré. Main est signalée non protégée ; une fusion peut déclencher Pages. Le retrait désactive uniquement Mélange et masque ses quatre presets sans supprimer de résultats ni d’historique. Aucun besoin de jeton personnel Supabase dans l’environnement cloud.
